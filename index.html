I build coding-agent tooling in Elixir.

My current work is about making coding agents useful on real codebases: give them a plan, limit the ways they can go wrong, and check the result.

I started writing software in 2012 and moved to Elixir in 2017. Before agents, I spent years working on CI, static analysis, and test infrastructure. I now use the same machinery to catch what agents get wrong. Models are good at producing plausible code; the surrounding system has to decide whether it belongs in production.

Building

Kogen

KogenAI/kogen

An Elixir framework for coding agents. You shape the feature and decide what done looks like. Kogen takes it from there: implementation, testing, review, and rework happen without a human in the loop. It finishes with a checked result or a clear reason it stopped.

Combobulate

combobulate.dev

Send it a Telegram message and it builds a website, deploys it, and connects a domain. I built the whole product with Kogen to see how the tooling held up outside a demo.
